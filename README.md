# Gestionnaire de playlist YouTube (JavaScript)

Site web pour créer sa propre playlist YouTube : ajouter, modifier et supprimer des vidéos, les marquer en favori et les écouter dans un lecteur intégré.

## Technologies

JavaScript, HTML, CSS, Bootstrap 5, localStorage

## Fonctionnalités

- Formulaire validé : nom, lien YouTube, durée (hh:mm:ss), favori
- Lecteur YouTube intégré avec lecture automatique
- Modification rapide : le formulaire se pré-remplit
- Suppression avec confirmation
- Calcul automatique de la durée totale de la playlist
- Mise en page adaptée aux téléphones (Bootstrap)

## Structure

- `index.html` : la page
- `projetFinal.js` : toute la logique (ajout, modification, suppression, lecteur, durée totale)
- `projetFinal.css` : les styles personnalisés

Bootstrap est chargé depuis un CDN, il n'y a rien à installer.

## Lancer le projet

Télécharger le dépôt et ouvrir `index.html` dans un navigateur.
